Un instrument desktop pentru analiza voltametriei ciclice (CV) a electroliților, realizat cu Python, PySide6 și Matplotlib. Interfața acceptă engleză și chineză simplificată; limba implicită este engleza.

## Funcții

- Importați fișiere Gamry DTA/TXT și fișiere de curbe Excel acceptate.
- Selectați ciclurile automat sau manual și analizați scanări de oxidare sau reducere.
- Calculați ariile integrate și sarcina folosind viteza de scanare configurată.
- Vizualizați curbe CV, potențiale de vârf și de debut, deplasări față de un ciclu de referință și verificări de calitate.
- Exportați registre Excel și figuri; salvați preferințele de afișare și procesare.

## Pornire

Windows, Python 3.10 sau mai nou. Rulați comenzile din directorul principal al proiectului.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Utilizare

1. Adăugați fișiere CV. Tabelele text trebuie să conțină secțiuni `CURVE... TABLE` cu coloanele `Vf` și `Im`.
2. Setați modul de analiză, intervalul de tensiune, viteza de scanare și ciclurile.
3. Porniți procesarea, verificați rezultatele și exportați.
4. Schimbați limba interfeței din **Settings → Language** sau **Settings → Preferences**. Alegerea este salvată.
