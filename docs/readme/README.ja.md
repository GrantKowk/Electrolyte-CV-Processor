Python、PySide6、Matplotlib を使用した、電解液のサイクリックボルタンメトリー（CV）解析用デスクトップツールです。画面は英語と簡体字中国語に対応し、既定は英語です。

## 機能

- Gamry DTA/TXT と対応する Excel 曲線ファイルを読み込みます。
- サイクルを自動または手動で選択し、酸化または還元掃引を解析します。
- 設定した掃引速度から積分面積と電荷を計算します。
- CV 曲線、ピーク電位、開始電位、基準サイクルからのシフト、品質チェックを確認できます。
- Excel と図を出力し、表示と処理の設定を保存します。

## 実行

Windows、Python 3.10 以降。以下のコマンドはプロジェクトのルートで実行してください。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## 使い方

1. CV ファイルを追加します。テキスト形式の曲線表には `CURVE... TABLE` セクションと `Vf`、`Im` 列が必要です。
2. 解析モード、電圧範囲、掃引速度、サイクル選択を設定します。
3. 処理を実行し、結果を確認して出力します。
4. **Settings → Language** または **Settings → Preferences** で画面の言語を切り替えます。選択は保存されます。
