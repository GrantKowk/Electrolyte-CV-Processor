Uma ferramenta de desktop para análise de voltametria cíclica (CV) de eletrólitos, desenvolvida com Python, PySide6 e Matplotlib. A interface oferece inglês e chinês simplificado; o inglês é o idioma padrão.

## Recursos

- Importar arquivos Gamry DTA/TXT e arquivos de curvas Excel compatíveis.
- Selecionar ciclos automaticamente ou manualmente e analisar varreduras de oxidação ou redução.
- Calcular áreas integradas e carga a partir da velocidade de varredura configurada.
- Exibir curvas CV, potenciais de pico e de início, deslocamentos em relação a um ciclo de referência e verificações de qualidade.
- Exportar planilhas Excel e figuras; salvar preferências de exibição e processamento.

## Execução

Windows, Python 3.10 ou superior. Execute estes comandos na raiz do projeto.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Uso

1. Adicionar arquivos CV. As tabelas de texto devem conter seções `CURVE... TABLE` com colunas `Vf` e `Im`.
2. Definir o modo de análise, a faixa de tensão, a velocidade de varredura e os ciclos.
3. Executar o processamento, verificar os resultados e exportar.
4. Alterar o idioma da interface em **Settings → Language** ou **Settings → Preferences**. A escolha é salva.

```powershell
.venv\Scripts\python -m pip install -r requirements.txt -r packaging/requirements-build.txt
.venv\Scripts\python -m PyInstaller --clean --noconfirm packaging/ElectrolyteCVProcessor.spec
```

O executável é gerado em `dist/`.
