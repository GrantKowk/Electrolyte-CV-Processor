Uno strumento desktop per l’analisi della voltammetria ciclica (CV) degli elettroliti, sviluppato con Python, PySide6 e Matplotlib. L’interfaccia supporta inglese e cinese semplificato; l’inglese è la lingua predefinita.

## Funzioni

- Importare file Gamry DTA/TXT e file di curve Excel supportati.
- Selezionare i cicli automaticamente o manualmente e analizzare scansioni di ossidazione o riduzione.
- Calcolare aree integrate e carica dalla velocità di scansione impostata.
- Visualizzare curve CV, potenziali di picco e di inizio, spostamenti rispetto a un ciclo di riferimento e controlli di qualità.
- Esportare cartelle Excel e figure; salvare le preferenze di visualizzazione e di elaborazione.

## Avvio

Windows, Python 3.10 o successivo. Eseguire questi comandi dalla directory principale del progetto.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Utilizzo

1. Aggiungere file CV. Le tabelle di testo devono contenere sezioni `CURVE... TABLE` con colonne `Vf` e `Im`.
2. Impostare modalità di analisi, intervallo di tensione, velocità di scansione e selezione dei cicli.
3. Avviare l’elaborazione, controllare i risultati ed esportare.
4. Cambiare lingua dell’interfaccia in **Settings → Language** o **Settings → Preferences**. La scelta viene salvata.

```powershell
.venv\Scripts\python -m pip install -r requirements.txt -r packaging/requirements-build.txt
.venv\Scripts\python -m PyInstaller --clean --noconfirm packaging/ElectrolyteCVProcessor.spec
```

L’eseguibile viene generato in `dist/`.
