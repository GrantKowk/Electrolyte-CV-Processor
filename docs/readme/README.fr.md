Un outil de bureau pour l’analyse de la voltampérométrie cyclique (CV) des électrolytes, développé avec Python, PySide6 et Matplotlib. L’interface propose l’anglais et le chinois simplifié ; l’anglais est la langue par défaut.

## Fonctionnalités

- Importer des fichiers Gamry DTA/TXT et les fichiers de courbes Excel pris en charge.
- Sélectionner les cycles automatiquement ou manuellement et analyser les balayages d’oxydation ou de réduction.
- Calculer les aires intégrées et la charge à partir de la vitesse de balayage configurée.
- Afficher les courbes CV, les potentiels de pic et de début, les décalages par rapport à un cycle de référence et les contrôles qualité.
- Exporter des classeurs Excel et des figures ; enregistrer les préférences d’affichage et de traitement.

## Exécution

Windows, Python 3.10 ou version ultérieure. Exécuter ces commandes à la racine du projet.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Utilisation

1. Ajouter les fichiers CV. Les tableaux texte doivent contenir des sections `CURVE... TABLE` avec les colonnes `Vf` et `Im`.
2. Régler le mode d’analyse, la plage de tension, la vitesse de balayage et les cycles.
3. Lancer le traitement, examiner les résultats et exporter.
4. Changer la langue de l’interface dans **Settings → Language** ou **Settings → Preferences**. Le choix est enregistré.
