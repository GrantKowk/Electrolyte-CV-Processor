Een desktopprogramma voor analyse van cyclische voltammetrie (CV) van elektrolyten, gebouwd met Python, PySide6 en Matplotlib. De interface ondersteunt Engels en vereenvoudigd Chinees; Engels is de standaardtaal.

## Functies

- Gamry DTA/TXT en ondersteunde Excel-bestanden met curves importeren.
- Cycli automatisch of handmatig selecteren en oxidatie- of reductiescans analyseren.
- Geïntegreerde oppervlakken en lading berekenen op basis van de ingestelde scansnelheid.
- CV-curves, piek- en aanvangspotentialen, verschuivingen ten opzichte van een referentiecyclus en kwaliteitscontroles bekijken.
- Excel-werkmappen en figuren exporteren en weergave- en verwerkingsvoorkeuren opslaan.

## Starten

Windows, Python 3.10 of hoger. Voer deze opdrachten uit in de hoofdmap van het project.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Gebruik

1. Voeg CV-bestanden toe. Teksttabellen moeten secties `CURVE... TABLE` met kolommen `Vf` en `Im` bevatten.
2. Stel de analysemodus, het spanningsbereik, de scansnelheid en de cyclusselectie in.
3. Start de verwerking, controleer de resultaten en exporteer ze.
4. Wijzig de interfacetaal via **Settings → Language** of **Settings → Preferences**. De keuze wordt opgeslagen.

## Windows-build

```powershell
.venv\Scripts\python -m pip install -r requirements.txt -r packaging/requirements-build.txt
.venv\Scripts\python -m PyInstaller --clean --noconfirm packaging/ElectrolyteCVProcessor.spec
```

Het uitvoerbare bestand wordt gemaakt in `dist/`.
